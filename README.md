# E-commerce Customer & Sales Intelligence

## Project Overview
An end-to-end data analytics project using Power BI to explore e-commerce sales, customer behaviour, product performance, and order trends.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## Dataset
The project uses five tables:
- Customers
- Orders
- Products
- Order_Details
- Payments

## Data Preparation
- Handled missing values.
- Cleaned customer and product information.
- Checked data types and prepared tables for analysis.
- Created relationships between the tables.

## Key Performance Indicators
- Total Revenue
- Total Orders
- Total Customers
- Total Quantity Sold
- Average Order Value
- Unique Products
- Delivered Orders
- Cancelled Orders

## Dashboard Insights
The dashboard includes:
- Monthly Revenue Trend
- Revenue by Product Category
- Revenue by Customer Segment
- Orders by Status
- Date and Order Status filters
